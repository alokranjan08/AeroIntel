# Step 1: Load and Clean Raw NTSB Dataset (Preview Highlight)
import pandas as pd
import numpy as np

# Load raw dataset (46,377 rows x 38 columns)
df_raw = pd.read_csv('data/aviation.csv', encoding='utf-8-sig')

# Filter U.S. incidents and drop irrelevant metadata
df = df_raw[df_raw['Country'] == 'United States'].copy()
drop_cols = ['Mkey', 'ReportNo', 'HasSafetyRec', 'OriginalPublishDate']
df.drop(columns=drop_cols, inplace=True, errors='ignore')

print(f"Cleaned U.S. incidents: {len(df):,} records")

Built on historical aviation data.

AeroIntel is an exploratory product concept built around historical aviation incident data from the NTSB and machine-learning analysis of incident characteristics.

NTSB Target Class Distribution

The target column HighestInjuryLevel was cleaned and missing values inferred from injury counts across 39,017 quality U.S. records.
